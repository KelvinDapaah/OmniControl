# 🤖 OmniControl Engine

OmniControl is a high-performance, modular Desktop Automation Engine designed to act as a "Body" for AI
models. It allows an AI (the "Brain") to perceive a Windows desktop environment and execute precise atom
ic actions via a standardized API.

## ✨ Key Features

- **Semantic Perception:** Uses Windows UI Automation (UIA) to extract labels, types, and coordinates of
 UI elements, moving beyond simple pixel-based clicking.
